About

A small lab for developer tools.

Lepid Labs is a software studio building tools for teams that keep their knowledge in the repository: design documents next to the code they describe, specifications that link to the operations that implement them, and assistants that read the same graph people do.

The public product is Weft, a documentation graph browser. Behind it sits a set of smaller libraries for code intelligence, knowledge storage, and agent orchestration. Each is built to stand on its own and to be embedded rather than to become a platform. They surface here as products when they are ready to be used by someone other than us.

Principles

Close to the code

Documentation, indexes, and configuration live in the repository and version with it. Nothing important lives only in a hosted service.

The host stays in charge

Our tools mount into a page or a workflow and leave URL, history, search, and data with the host. Navigation is an output the host may act on, not an action we take.

One thing each

Libraries are small, plainly named, and composable. A product is a composition; a library never depends on the product that uses it.

Open where it helps

Weft is MIT licensed and developed in the open. Anything that is useful on its own and safe to share follows the same path.

Contact

The organisation lives at github.com/Lepid-Labs. Questions and bug reports about Weft go to its issue tracker; the FAQ answers the common ones.
