Weft

Public MIT

A documentation graph browser that lives in the repository alongside the code. Design docs, specs, API definitions, and diagrams become nodes with typed, anchor-level relationships between them. Any document is an entry point; navigation is the product.

It runs as a CLI over a local checkout, or embeds into any page as a single script pointed at a repository or a base URL. This site's FAQ and Docs pages are Weft embedded.

How we build

01

Documentation is a graph

A folder of files hides the relationships that matter. We treat every cross-reference as a typed edge, resolvable to a heading, a slide, or an operation, and make it navigable.

02

Embed, do not own

Our tools mount into the page, repository, or workflow you already have. The host keeps its URL, its history, its search, and its data. We supply the part it does not have.

03

Small pieces, plainly named

Each library does one thing and can be reasoned about on its own. Products compose them; nothing depends on the composition.
