# 0008 Scope of the Documentation page

Status: open

## Context

The Docs page renders Weft's documentation from the pinned checkout. That includes Weft's internal specification
documents (plan, research, design decisions) as well as its user guides.

## Decision

Not yet made. The options are to keep showing everything, or to show only the user guides.

## Consequences

Showing only the guides makes the page a clearer product manual; showing everything demonstrates Weft on a richer
graph.
